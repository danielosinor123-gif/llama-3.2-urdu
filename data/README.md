# Data

## Layout

- `seed/` — hand-written formatted Urdu drama scripts (20 episodes, 4 genres: family_drama, romance, social_issues, thriller). One JSONL episode per row.
- `raw/` — pulled from Hugging Face by `src/data/ingest_hf.py`. Contains provenance per row. Not committed (large).
- `final/` — generated by `src/data/build_dataset.py`: `train.jsonl`, `val.jsonl`, `test.jsonl`, `build_report.json`. Splits are episode-level and leakage-free (verified by `src/stress_test.py`).
- `urdu_demo.jsonl` — original 10-row demo set, kept for reference.

## Format

Seed episode:

```json
{"episode_id": "family-01", "genre": "family_drama", "title": "...", "characters": ["..."], "character_sheet": {"...": "..."}, "scenes": [{"scene_number": 1, "setting": "...", "lines": [{"speaker": "...", "action": "...", "text": "..."}]}]}
```

Training row (single scene):

```json
{"prompt": "...", "response": "...", "source": "seed", "episode_id": "family-01", "genre": "family_drama"}
```

Training row (multi-turn episode conversation):

```json
{"messages": [{"role": "system", "content": "..."}, {"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}], "source": "seed_chat", "episode_id": "family-01", "genre": "family_drama"}
```

## Rules

- Never add a scene from an episode that exists in another split (stress test enforces this).
- All text must pass `src/data/filter_urdu.py` (no Devanagari, no Hindi-isms, Arabic-script ratio threshold).
- Dedup happens before splitting.
- Rebuild deterministically: `python src/data/build_dataset.py` produces identical splits every time.
